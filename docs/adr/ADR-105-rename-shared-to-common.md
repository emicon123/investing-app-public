# ADR-105: Rename `packages/shared` to `packages/common`

**Date:** 2026-10-24
**Status:** Accepted
**Scope:** monorepo layout, every app's build wiring and imports. No runtime behaviour changes.
**Related:** task 169 (`.claude/tasks/169-rename-shared-to-common.task.md`), ADR-077 (repo
consolidation), task 158 (per-app `src/api/`), task 170 / ADR-106 (the first work that builds on
the new names).

## Context

The cross-app code lives in `packages/shared/` and is published to the workspace as `@shared/*` npm
packages and the Go module `investing-app/shared-go`. On 2026-10-24 the owner asked for the folder
and its package names to say `common`. The word "shared" is also used in this repo for things that
are not this code: the shared Postgres stack (`infra/shared/`, service `db-shared`), the shared Nginx,
and the AGENTS.md rule about moving duplicated code into shared modules. One name for one concept
makes `rg` results and agent instructions easier to read.

Task 170 (portfolio redesign) adds a lot of new cross-app code. Doing the rename first means that
code is written with the final names and is not touched twice.

## Decision

A pure rename with zero behaviour change, done as one atomic commit
(`refactor: rename packages/shared to packages/common`). Directories move with `git mv` so history
follows.

| Today | After |
| --- | --- |
| `packages/shared/` | `packages/common/` |
| `packages/shared/ts` (npm `@shared/app-core`) | `packages/common/ts` (npm `@common/app-core`) |
| `packages/shared/ui` (npm `@shared/ui-primitives`) | `packages/common/ui` (npm `@common/ui-primitives`) |
| `packages/shared/go/shared-go` (Go module `investing-app/shared-go`) | `packages/common/go/common-go` (Go module `investing-app/common-go`) |

Every place that names the old path or package changes in that commit. The task file lists them.
These are the ones that fail silently or break deploys if missed:

- **Tailwind v4 `@source` directives** in each app's `src/index.css`
  (`@source "../../../../packages/shared/ui/src"` and `.../shared/ts/src`). A wrong path does not
  fail the build. Classes used only inside the common UI package just disappear from the CSS.
  This happened on 2026-10-18, when the hamburger shell and dialog backgrounds vanished. DevOps
  compares built CSS size before and after, and greps the built CSS for a class that only
  `packages/common/ui` uses.
- **`.github/workflows/deploy-pi.yml` path filter** (`packages/shared/*` in the app-mapping `case`).
  If it is left unchanged, a change under `packages/common/` stops redeploying the three apps.
- **`.github/workflows/go-tests.yml`**: the module matrix entry and the `paths:` filters.
- **The standalone sibling `apps/{portfolio-b,portfolio-c}-investing-app/package.json` workspaces**, the root
  `package.json` workspaces, `vitest.config.mts` (`packages/shared/*/src/**/*.test.*`), and
  `package-lock.json`. The lockfile is regenerated with `npm install`, never hand-edited.
- **Go**: `go.work`, each backend's `go.mod` (`require` and `replace` pointing at the new path),
  every import `investing-app/shared-go/...` becomes `investing-app/common-go/...`, and the
  backend and nginx Dockerfiles (`COPY packages/shared ...`).

### Not renamed (deliberately)

- **History.** `.claude/tasks/done/*`, the bodies of existing ADRs (`docs/adr/ADR-001` to
  `ADR-104`) and old diagram write-ups keep the path names they were written with. This ADR is the
  key for reading them: wherever an older document says `packages/shared/...`, `@shared/...` or
  `shared-go`, read `packages/common/...`, `@common/...` or `common-go`.
- **Applied Flyway migrations** (`apps/*/db/migration/V*.sql`). Editing an applied file changes its
  checksum and the Flyway runner then refuses to migrate. None mention the path today (only the
  `db/README.md` files do, and those are updated). If one ever does, it stays as it is.
- **Things that are "shared" but are not this code**: `infra/shared/` (the shared Postgres compose
  stack), the `db-shared` service and the `shared-infra` compose project, Docker container names,
  the "shared Nginx", and feature names such as `history-chart-shared`.
- **Identifiers and prose.** Local import aliases such as `SharedPortfolioPage` and comments that use
  the English word "shared" are not part of the gate and may stay. New code uses "common". The one
  wording change in prose is AGENTS.md's rule about moving code edited the same way in 2 to 3
  apps: it now says "common modules" (`packages/common`).
- **`graphify-out/`** is regenerated by `graphify update .`, not edited.

### Live docs updated in the same commit (by DevOps, not by this ADR)

`AGENTS.md`, `apps/*/CLAUDE.md`, `.claude/agents/*.md`, `docs/architecture/08-monorepo-layout.md`,
`docs/architecture/12-portfolio-bpps-and-shared-packages.md` and any other current-state doc under
`docs/architecture/` describe the tree as it is after the rename. The file name
`12-portfolio-bpps-and-shared-packages.md` keeps its name so existing links keep working.

## Consequences

- **Precondition.** Many of the files that carry the old name currently hold the owner's
  uncommitted work: the TanStack Table 9 / React Router 8 upgrade in `package.json`, `go.mod`,
  `go.sum`, the Dockerfiles, `compose.yml`, `go-tests.yml` and `packages/shared/...`. That work is
  committed first. DevOps runs the rename only on a tree where `git status` shows none of the paths
  it touches, so the atomic commit never picks up unrelated changes.
- **Gate.** The rename is done when all of these pass:
  - `rg -n "packages/shared|@shared/|shared-go"` (excluding `.claude/tasks/done`, `docs/adr`,
    `graphify-out`, `node_modules` and `package-lock.json` before regeneration) returns nothing.
  - `go build ./... && go vet ./...` and the full `go test ./...` (never `-short`) pass in all
    four modules.
  - `npm install`, `npx vitest run` and `npm run build` pass in all three frontends.
  - `docker compose build` of the 3 nginx and 3 backend images succeeds.
  - The built-CSS check above passes.
  - `graphify update .` has been run.
- **Deploy.** All three apps redeploy once, because the path filter maps `packages/common/*` to all of
  them. The orchestrator does that deploy. Images and runtime behaviour are otherwise identical.
- **Task 170** and everything after it use `packages/common/{ts,ui,go}`, `@common/app-core`,
  `@common/ui-primitives` and `investing-app/common-go`.
